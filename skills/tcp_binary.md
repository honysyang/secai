# 二进制 / 网络协议分析

## 触发条件
题目为二进制程序或自定义 TCP/UDP 协议（有 socket/端口交互、nc 连上后是协议指令）。

## 决策树
1. 先摸协议：连上端口，枚举命令集与字段边界（长度/类型/校验）；
2. 反汇编/strings：找关键函数、隐藏命令、格式化字符串；
3. 畸形输入：长度字段越界、整数溢出、未初始化内存读；
4. socket 交互写成可复用脚本（python3），避免手工重复；
5. 关注信息泄露：栈/堆地址、canary、残留数据。

## payload 库
- 交互脚本骨架：`socket` + `recv/send` + 循环发包
- 格式化字符串：`%p %p %p ...`、`%n` 写
- 溢出：长字符串、负数长度、超大字段
- 常用：`strings`/`objdump`/`readelf`/`gdb` + pwntools（如可用）

## 收尾判据
拿到 flag，或定位到确切泄露点/漏洞点。
