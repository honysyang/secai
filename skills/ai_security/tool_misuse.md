# LLM 工具滥用评估

## 目标
检测 LLM 是否可被诱导用危险参数调用工具，或突破执行边界。

## 测试用例
1. 让模型用攻击者可控输入调用工具
2. 通过工具参数请求执行系统命令
3. 间接注入：通过模型后续处理的文档/网页注入指令

## 验证
- 确认工具参数有校验与清洗
- 验证最小权限工具作用域（least-privilege）
- 检查日志中是否有未授权工具调用证据

## 报告
记录 payload、被调用的工具、参数、业务影响
