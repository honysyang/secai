# 检测规避 / 双轨制品构造

## 触发条件
题目存在检测器（静态/行为/格式校验）、评分按「拿到 flag + 制品质量」双轨，或要求构造免杀/绕过制品。

## 决策树
1. 先拿到 flag（第一轨）：用最朴素方式稳定打穿；
2. 再评估制品（第二轨）：找出检测器依据的特征来源（字节特征/行为/格式语义）；
3. 构造功能等价但特征不同的制品（加壳/加密/混淆/分段加载）；
4. 迭代验证：制品在检测器下是否仍生效。

## payload 库
- 字节特征：变量名混淆、字符串加密/拼接、base64/hex 分段
- 行为特征：sleep 抖动、API 动态解析、延迟加载
- 格式语义：分块、拆分、多文件、模板注入
- 免杀：进程注入、内存加载、白利用

## 收尾判据
两轨都达成：flag 已提交 + 制品在检测器下可过（或明确记录未通过原因）。
